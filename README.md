# 🦜 Cockatiel

A modern, high-performance real-time messaging and voice/video calling mobile application built with React Native (Expo) and Node.js.

## 📁 Project Structure

```
cockatiel/
├── frontend/             # React Native (Expo) mobile client application
├── backend/              # Node.js + Express + Socket.IO server
├── resources/            # Design mockups, UI screenshots, and assets
├── PLANNING.md           # Master architecture and technical planning document
└── README.md             # Project overview
```

## 🚀 Technology Stack

- **Frontend:** React Native, Expo SDK, TypeScript, Expo Router, NativeWind (Tailwind CSS), Lucide Icons, WebRTC
- **Backend:** Node.js, Express.js, TypeScript, Socket.IO, PostgreSQL, Prisma ORM, Redis
- **Storage & Media:** Cloudinary / AWS S3
- **Push Notifications:** Firebase Cloud Messaging / Expo Push
